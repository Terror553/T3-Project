# Website Features (Observed)

This file lists visible features found by browsing the two sites. Items are grouped by site and by feature area. "Linked" means the feature is present as a navigation item or footer link but was not fully explored in depth.

---

## 1. lithium.coldfiredzn.com (Lithium)

### 1.1. Authentication and Accounts
- Login page link in header and hero CTA.
- Register page link in header and hero CTA.
- Profile pages for users (linked from avatars and usernames).

### 1.2. Navigation and Core Pages
- Home page with news feed and community widgets.
- Forum page with categories and search.
- Status page (server status view).
- Rules page (linked).
- Members page (directory and ranking views).
- Store link (linked).

### 1.3. Community and Forum
- Forum category list with topic and post counts.
- Last post preview per category (topic title, author, timestamp).
- Forum search input.
- Collapsible forum category header.
- Breadcrumb navigation on forum.

### 1.4. Members Directory
- Directory overview with lists: Staff members, Most posts, Highest forum reaction scores, Most trophies, Registered members.
- Member search by name.
- Group filter dropdown (Admin, Moderator, Member, Unconfirmed Member).
- New members list with avatars.
- Links to member profile pages.

### 1.5. News and Updates
- News posts with title, author, timestamp, read time, and excerpt.
- Latest news widget with thumbnail, date, and read time.

### 1.6. Community Status Widgets
- Online staff widget.
- Online users widget with avatars and profile links.
- Community statistics (threads, posts, registered users, online guests, latest member).

### 1.7. Server and Social Integrations
- Minecraft server status block (server address + players online placeholder).
- Discord invite block (users online placeholder).
- Footer social icons (Twitter, Instagram placeholders).

### 1.8. Footer and Site Controls
- Cookie notice link.
- Terms and Conditions link.
- Privacy Policy link.
- Dark mode toggle.
- Auto language selector.
- "Powered by NamelessMC" footer credit.
